# 真心话大冒险（卡牌版）
> 🌐 English version: [en/109_Truth_or_Dare.md](en/109_Truth_or_Dare.md)

> 货架位置：照片 155056 C3 层（小盒，“真心话大冒险”）
> 市面上有许多不同厂商的“真心话大冒险”卡牌，题目各不相同，但玩法基本一致。

## 基本信息
| 项目 | 内容 |
|---|---|
| 类型 | 派对破冰游戏 |
| 人数 | 3 人以上，越多越热闹 |
| 时长 | 不限 |

## 配件（常见）
**真心话**卡（问题）、**大冒险**卡（任务），有些版本加入转盘、骰子或“惩罚卡 / 免罪卡”。

## 通用玩法
1. 用转瓶子、掷骰子、抽签或其他游戏的输家，决定**本轮被选中的人**。
2. 被选中的人选择：
   - **真心话**：抽 1 张真心话卡，必须**诚实回答**；
   - **大冒险**：抽 1 张大冒险卡，必须**完成任务**。
3. 拒绝回答或拒绝完成：接受事先约定的惩罚（如喝饮料、换一张更难的卡、表演节目）。
4. 下一轮重新决定人选。

## 常见变体
- 和其他游戏组合：例如 UNO、吹牛、狼人杀的输家进入真心话大冒险环节。
- 难度分级：有些卡牌按颜色分轻松 / 中等 / 刺激，按在场关系选择。

## 注意
- 开局先约定**底线**（不涉及隐私的问题、不做危险或令人不适的任务），任何人都可以“跳过”。
- 本盒的具体卡牌内容和附加规则以盒内说明为准。

## 深入玩法：教学、策略与易错点

> 本节是整理者根据上文规则和公开资料做的归纳，方便快速上手。与盒内说明书冲突时，以说明书为准。

**一句话介绍**：经典破冰：被选中的人二选一，回答真心话或执行大冒险。

| 维度 | 参考 |
|---|---|
| 支持人数 | 3–20 人 |
| 推荐人数 | 5-8 人 |
| 单局时长 | 10–60 分钟 |
| 建议年龄 | 12+ |
| 复杂度 | ●○○○○ 入门 |
| 标签 | 派对 · 破冰 · 聊天 |

### 5 分钟教学顺序

1. 讲选人方式
2. 选真心话或大冒险
3. 拒绝时的惩罚（家规）

### 进阶策略

- 事先约定尺度和底线。
- 题目可以按场合筛选。

### 常见错误与容易混淆的规则

- 尊重每个人的边界。

### 适合 / 不适合

- 👍 **适合**：人多的聚会；新手破冰、长辈也能马上上手
- 👎 **不太适合**：暂无明显的不适合场景

## 详细补充：配件清点、示例局、计分、FAQ、人数与变体

> 本节是整理者根据上文规则编写的**演示与补充**，用来帮助理解；示例中的数字为演示用。与盒内说明书冲突时，**以说明书为准**。

### 配件清点清单

- [ ] 真心话**卡（问题）、**大冒险**卡（任务），有些版本加入转盘、骰子或“惩罚卡 / 免罪卡”。

开局前检查：
- 开盒后先按说明书的配件表逐项清点；卡牌按类型分开数，少牌会直接影响平衡。
- 确认指示物、骰子、计分轨标记齐全；缺失时可以用硬币或其他游戏的通用指示物临时代替。
- 把参考卡/玩家帮助卡发给每人，第一局能省很多翻规则的时间。

### 完整示例局（演示）

1. 开局先约定底线：不涉及隐私、不做危险任务，谁都可以说'跳过'。
2. 用转瓶子选出本轮的人：我。
3. 我选真心话，抽卡并诚实回答。
4. 下一个人选大冒险，完成任务。
5. 拒绝的人接受事先约定的轻度惩罚。

### 计分示例

- 通常不计分；可以约定次数或积分。

### 规则 FAQ / 易混淆点裁定

- **问：可以拒绝吗？**  
  答：可以，按约定接受惩罚或使用免罪卡。

### 不同人数的差异

- 3 人以上。
- 推荐人数：5-8 人。

### 官方变体与扩展

- 可与其他游戏组合。
