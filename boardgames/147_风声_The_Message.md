# 风声（The Message，千骐动漫 / 千智）

> 货架位置：照片 155125 G4 层，黑色盒 ×4（盒侧印「千骐动漫」「千智」标志，以及书法体「风声」）
> 同一层另有 2 盒「犯罪现场」，同为千骐 / 千智出品，见文档 135。

## 基本信息
| 项目 | 内容 |
|---|---|
| 出版 | 千骐动漫（《永恒之轮》的出版商）；后来有腾讯 QQ 游戏网络版 |
| 题材 | 改编自 2009 年同名谍战电影《风声》 |
| 人数 / 时长 / 年龄 | 3–9 人 / 30–60 分钟 / 12+（不同来源写 10+ 或 12+，以盒面为准）|
| 类型 | 隐藏身份、阵营推理、手牌管理；卡牌既是情报也是功能牌 |
| 配件（基础版）| 身份牌 9 张、游戏牌 81 张、角色牌 18 张，共 108 张 |

## 阵营与胜利条件
| 阵营 | 胜利条件 |
|---|---|
| 潜伏战线（红）| 本阵营任一玩家面前集齐 **3 张红色情报**，全阵营一起获胜 |
| 军情处（蓝）| 本阵营任一玩家面前集齐 **3 张蓝色情报**，全阵营一起获胜 |
| 打酱油的（中立）| 完成自己角色牌上的“机密任务”，只算个人胜利 |

- **黑色情报**是假情报。玩家面前累积 **3 张黑色情报就会死亡**。
- 只有放在玩家面前的情报才算“获得”，手牌不算。

## 准备
1. **挑角色**：每人随机拿 2 张角色牌，选 1 张。
   - 带“潜伏”标记的角色要面朝下盖着；普通角色面朝上公开。
2. **发身份**：按人数取身份牌，随机每人 1 张，秘密查看。
   - 官方建议第一次玩用偶数人数，并且不放“打酱油的”。
3. **发手牌**：每人发起始手牌（数量见说明书）。

## 回合流程
1. **抽牌阶段**：抽 2 张牌。
2. **出牌阶段**：可以打出功能牌（左上角写着名称和效果）。
3. **传递情报**：必须且只能**传出 1 张手牌作为情报**。传递方式看牌右上角的印章：
   - **密电**：面朝下传给相邻玩家，沿逆时针方向逐人传。每个人决定接收（翻开放在自己面前）或者不接收，不接收的人不能偷看。传回到传出者手里时，传出者必须接收。
   - **直达**：面朝下交给任意一名玩家。对方接收，或者直接退回，退回时由传出者接收。
   - **文本**：和密电一样逐人传，但情报**面朝上**，所有人都能看到。
   - 手上没有牌可以传出的玩家**输掉游戏**。
4. **结束阶段**：通常跳过。

## 主要功能牌
| 卡牌 | 效果 |
|---|---|
| 锁定 | 指定一名玩家，本回合情报传到他面前时他必须接收 |
| 调虎离山 | 指定一名玩家本回合不参与情报传递（对传出者和被锁定者无效）|
| 截获 | 别人传情报时打出，直接拿走传递中的情报。官方说明：截获不受锁定、调虎离山影响；多人截获时后打出的先结算 |
| 退回 | 情报到达自己面前时打出，让情报反方向传递（被锁定时无效）|
| 破译 | 情报到达自己面前时先查看内容 |
| 烧毁 | 烧掉某人面前 1 张假情报 |
| 识破 | 让一张正在打出的卡牌无效 |
| 试探 | 面朝下交给一名玩家，牌上写着“我打赌你是××（阵营）”。对方必须按自己的真实身份照牌上要求做（例如弃牌或抽牌），只有双方能看到内容 |
| 真伪莫辨 | 从牌堆顶翻出等于人数的牌，逆时针依次发给每名玩家当作情报 |
| 扩展：转移、调包 | 强行把情报转给别人，或者用手牌换掉传递中的情报 |

## 死亡与出局
- **死亡**：面前第 3 张黑色情报到位时死亡。弃掉全部手牌和情报，公开角色牌和身份牌，并结算“死亡时”触发的角色技能。
- **输掉游戏**：没牌可传时出局。同样公开身份，但**不触发**死亡技能。

## 易错点
- 牌作为情报时，左上角的功能文字**不生效**。
- 在“接收 / 不接收”的决定时点，不能打出任何牌，也不能发动技能。
- 同一时点有多张响应牌时，按“后出先结算”。
