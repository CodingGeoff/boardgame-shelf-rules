# 猫咪卷饼羊（Taco Cat Goat Cheese Pizza，台译 猫咪比萨卷饼羊）

> 货架位置：照片 155046 顶层卡盒（白标“猫咪卷饼羊”×2，蓝标“58 猫咪卷饼羊?”）

## 基本信息
| 项目 | 内容 |
|---|---|
| 设计 | Dave Campbell |
| 出版 | Blue Orange（2018）|
| 类型 | 反应、口令、拍牌 |
| 人数 / 时长 / 年龄 | 2–8 人 / 10–30 分钟 / 8+ |
| 配件 | 64 张牌：塔可、猫咪、山羊、起司、比萨，以及特殊牌猩猩、土拨鼠、独角鲸（异色款用来干扰判断）|

## 准备
- 洗匀后发牌：**2–5 人每人 12 张**；6–8 人平均发完，多余的放回盒内。
- 每人把牌**面朝下**叠成自己的牌堆，不能看。

## 玩法
1. 从发牌者左手边开始，**向外**翻开牌堆顶的牌放到中央，同时按顺序喊口令：
   **塔可 → 猫咪 → 山羊 → 起司 → 比萨 →** 塔可 → …
2. 每人接着喊下一个词，**保持固定节奏**。
3. **翻出的牌 = 喊出的词**：所有人拍中央牌堆，**最慢的人**收走中央所有牌，放到自己牌堆底。从他开始重新喊“塔可”。
4. **特殊牌**：所有人先做动作，再拍牌（动作做错或最慢的人收牌）。
   - 猩猩：双手捶胸
   - 土拨鼠：双手拍桌
   - 独角鲸：双手合十举过头顶
5. **失误**：拍错、手伸出去又缩回、喊错口令、节奏卡住、向内翻牌偷看，都算输掉这一次，收走中央所有牌。

## 结束
出完牌的玩家**仍然要照顺序喊口令**（但不翻牌）。他在下一次拍牌时**最先拍到**（或最先做对动作），就获胜。

## 深入玩法：教学、策略与易错点

> 本节是整理者根据上文规则和公开资料做的归纳，方便快速上手。与盒内说明书冲突时，以说明书为准。

**一句话介绍**：一边出牌一边按顺序念“玉米卷、猫、山羊、奶酪、披萨”，牌面和念的词一样时，所有人拍牌。

| 维度 | 参考 |

| 支持人数 | 2–8 人 |
| 推荐人数 | 4-8 人 |
| 单局时长 | 10–30 分钟 |
| 建议年龄 | 8+ |
| 复杂度 | ●○○○○ 入门 |
| 标签 | 反应 · 派对 · 家庭 |

### 5 分钟教学顺序

1. 讲顺序念词
2. 讲匹配时拍手（最后拍的人收牌）
3. 讲三种特殊动作牌（大猩猩、独角鲸、土拨鼠）
4. 最先出完牌并拍中的人获胜

### 进阶策略

- 念词节奏要稳，别被对手的语速带乱。
- 特殊动作牌出现时先做动作，再去拍。
- 手牌少时更要专注，最后一张必须拍中才能获胜。

### 常见错误与容易混淆的规则

- 拍错（不该拍时拍了）要收牌。
- 翻牌时要向外翻。

### 适合 / 不适合

- 👍 **适合**：人多的聚会；新手破冰、长辈也能马上上手；喜欢手速和刺激的人
- 👎 **不太适合**：想安静慢慢思考的人
