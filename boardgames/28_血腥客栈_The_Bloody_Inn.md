# 血腥客栈（The Bloody Inn）

> 货架位置：155036 中层

## 基本信息
| 项目 | 内容 |
|---|---|
| 设计 | Nicolas Robert |
| 出版 | Pearl Games（2015）|
| 类型 | 手牌管理、黑色幽默 |
| 人数 / 时长 / 年龄 | 1–4 人 / 30–60 分钟 / 14+ |
| 主题 | 1831 年法国乡间，一家人开客栈，暗中谋财害命 |

## 配件
- 旅客卡：农民、手艺人、贵族、宗教人士、军人，以及**警察**（宪兵）等，每张标有等级（1–4）和价值
- 农民卡（作为起始雇员或共犯）、客房卡
- 法郎（金钱）、钥匙标记、玩家板

## 准备
- 每人拿起始农民（共犯）卡，以说明书为准。
- 旅客牌堆洗混；客房按人数排开。
- 每人起始拥有少量法郎和钥匙。

## 每轮流程
1. **旅客入住**：从牌堆翻旅客卡，放进客栈房间。
2. **行动阶段**：从起始玩家开始，每人执行 **2 个行动**，从以下 5 种中选择（可以重复）：
   | 行动 | 说明 |
   |---|---|
   | **贿赂（Bribe）** | 把旅客招为**共犯**（收入手牌），费用按其等级 |
   | **建造（Build）** | 把手牌中的旅客当作**附属建筑**打出，建筑可以用来掩埋尸体，并提供持续能力 |
   | **杀害（Kill）** | 杀掉一名旅客，在自己面前形成一具**尸体** |
   | **掩埋（Bury）** | 把尸体埋进一座有空位的建筑里（需要满足建筑容量） |
   | **洗钱（Launder）** | 把**已掩埋**的尸体身上的钱变成自己的法郎 |
   - **费用规则**：执行需要某个等级的行动时，要从手牌中**弃掉与该等级数相同数量的共犯卡**（以说明书为准），即“费用 = 所需等级数量的弃牌”。
3. **结算阶段**：
   - **客栈收入**：仍住在客栈里、没被杀的旅客为客栈带来收入。
   - **警察检查**：如果有**警察**在店里，而你**还有尸体没埋**，**每具未埋尸体罚 10 法郎**（以说明书为准）。
   - 支付共犯的薪水（如果需要）。
4. 起始玩家轮转。

## 游戏结束
- 旅客**牌堆用完两次**后游戏结束。
- 计分：现金 + 建筑与卡牌提供的价值，减去负债等。**钱最多者获胜**。

## 策略要点
- 先建造建筑，有地方埋尸才敢大肆下手。
- 盯住警察的出现时机，别让尸体堆在外面。
- 手牌既是行动成本也是资源，留哪张、弃哪张是核心决策。

## 深入玩法：教学、策略与易错点

> 本节是整理者根据上文规则和公开资料做的归纳，方便快速上手。与盒内说明书冲突时，以说明书为准。

**一句话介绍**：19 世纪法国乡下的黑店：招揽、贿赂、杀掉旅客，埋尸、洗钱，最后比谁最有钱。

| 维度 | 参考 |
|---|---|
| 支持人数 | 1–4 人 |
| 推荐人数 | 2-3 人 |
| 单局时长 | 30–60 分钟 |
| 建议年龄 | 14+ |
| 复杂度 | ●●●○○ 中度 |
| 标签 | 黑色幽默 · 经济 · 卡牌 · 策略 |

### 5 分钟教学顺序

1. 讲旅客卡的等级和职业
2. 讲 4 种行动：贿赂（招为同伙）、杀人、埋尸、建附属建筑
3. 说明尸体没埋要被警察查

### 进阶策略

- 先贿赂几个低级同伙，后面行动才付得起。
- 附属建筑既能埋尸，又有持续效果，越早建越好。
- 留意警察何时出现，手上有尸体就危险了。

### 常见错误与容易混淆的规则

- 行动需要弃同伙卡支付，等级要求见卡面。
- 未埋的尸体在回合末会带来风险或罚款（以说明书为准）。

### 适合 / 不适合

- 👍 **适合**：大多数桌游爱好者
- 👎 **不太适合**：暂无明显的不适合场景

### 完整示例局（演示）

1. 我用 1 个行动'贿赂'一位旅客做帮手（弃相应等级的帮手卡支付）。

3. 下回合'掩埋'尸体到附属建筑里，拿到旅客的钱。
4. 警察来时，没掩埋的尸体会被罚。
