# 脏小猪（Drecksau / Dirty Pig）

## 基本信息
| 项目 | 内容 |
|---|---|
| 设计 / 美术 | Frank Bebenroth |

| 类型 | 互相陷害（Take That）、轻松家庭卡牌 |
| 人数 / 时长 / 年龄 | 2–4 人（英文版 Dirty Pig 可到 6 人）/ 约 10 分钟 / 7+ |

## 目标
**第一个让自己所有小猪都变脏的人获胜**。“只有脏猪才是快乐的猪！”

## 准备
- 每人面前摆 **3–5 只干净小猪**（人越少猪越多，具体张数见说明书），干净面朝上。
- 每人 **3 张手牌**，剩下的作为牌库。

## 回合
**打出 1 张牌**并执行效果，然后补回 3 张。如果没有能用的牌，可以按说明书**弃掉全部手牌**换 3 张新牌，本回合结束。

| 卡牌 | 效果 |
|---|---|
| 泥巴 | 让自己 1 只干净小猪变脏（翻面）|
| 下雨 | **所有人**（包括自己）的脏猪都被洗干净，除非在猪圈里 |
| 猪圈 | 盖在自己的 1 只猪上，防下雨 |
| 闪电 | 劈掉别人的 1 个猪圈 |
| 避雷针 | 保护猪圈不被闪电劈 |
| 猪圈门（锁）| 让猪圈里的猪不怕农夫 |
| 农夫（洗澡）| 把别人的 1 只脏猪洗干净 |

> 各版本卡名略有不同（例如 Drecksau Total 加入了额外泥巴、口红等新卡），以盒内说明书为准。

## 易错点
- 下雨也会洗你自己的猪，出牌前先看看谁的脏猪最多。
- “猪圈 + 门 + 避雷针”的组合完全无敌。

## 深入玩法：教学、策略与易错点

> 本节是整理者根据上文规则和公开资料做的归纳，方便快速上手。与盒内说明书冲突时，以说明书为准。

**一句话介绍**：让自己的猪全部变脏：出泥浆牌弄脏猪，用猪圈和避雷针保护，再用雨水和农夫洗别人的猪。

| 维度 | 参考 |
|---|---|
| 支持人数 | 2–4 人 |
| 推荐人数 | 3 人 |
| 单局时长 | 15–20 分钟 |
| 建议年龄 | 6+ |
| 复杂度 | ●○○○○ 入门 |
| 标签 | 家庭 · 卡牌 · 互动 · 儿童 |

### 5 分钟教学顺序

1. 讲每人几只干净猪
2. 泥浆、雨、农夫、猪圈、锁门、避雷针等牌
3. 先让所有猪变脏的人获胜

### 进阶策略

- 先给脏猪盖猪圈再锁上，防农夫洗猪。
- 雨牌会洗掉没有猪圈的猪，手里留一张很有威胁。
- 避雷针防止猪圈被闪电劈掉。

### 常见错误与容易混淆的规则

- 没有可出的牌时，可以弃牌重抽。
- 锁门的猪圈不能被农夫进入。

### 适合 / 不适合

- 👍 **适合**：带小朋友的家庭；等人、饭前饭后的短时间
- 👎 **不太适合**：暂无明显的不适合场景

### 完整示例局（演示）

1. 每人面前 3 只干净的猪。
2. 我打出'泥巴'弄脏自己一只猪。
3. 对手打出'下雨'，所有脏猪都被洗干净。
4. 我打出'谷仓'保护猪，再加'避雷针'防闪电。

### 计分示例

- 先让自己所有猪都变脏的玩家获胜。

### 规则 FAQ / 易混淆点裁定

- **问：猪圈能防止猪被洗吗？**  
  答：能防下雨，但闪电可以劈掉别人的猪圈，避雷针可以保护猪圈；猪圈门防农夫。

### 不同人数的差异

- 2–4 人，人越少每人的猪越多。
- 推荐人数：3 人。

### 官方变体与扩展

- Drecksau Total 等版本加入新卡；英文版 Dirty Pig 可到 6 人。
