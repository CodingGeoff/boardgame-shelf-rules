## Overview

Draw and place tiles to build medieval France; place meeples as robbers, knights, monks or farmers to score features.

## Setup

1. Place the start tile; each player takes meeples.

## How to play

1. Draw a tile and place it matching edges.
2. Optionally place a meeple on a feature of that tile (not one already occupied).
3. Completed features score immediately; return meeples.

## Game end & scoring

- When tiles run out, score incomplete features and farms; most points wins.

## 5-minute teaching order

1. **Goal first:** When tiles run out, score incomplete features and farms; most points wins.
2. **What you do on a turn:** Draw a tile and place it matching edges.
3. **Setup check:** Place the start tile; each player takes meeples.
4. **The one rule people forget:** You cannot place on an occupied connected feature.
5. Play one open-handed practice round, then start for real.

## Strategy tips

- Meeples are limited.
- Farmers decide close games.
- Join features to contest majorities.

## Common mistakes

- You cannot place on an occupied connected feature.

## Good for / not for

- **Good for:** most board gamers
- **Not ideal for:** no obvious bad fit

Before you start:
- Count the components against the rulebook list; sort cards by type — a missing card can break the balance.
- Check tokens, dice and score markers; coins or generic tokens can stand in for missing pieces.
- Hand out reference cards before the first game to save rulebook time.

### Worked example (illustrative)

1. Draw a tile and place it matching edges.
2. Place a meeple on the city.
3. The city completes: 2 tiles × 2 = 4 points; meeple returns.
4. His road connects to mine, sharing.
5. Score incomplete features and farms at the end.

### Scoring example

- City 2/tile (+2 shield), road 1/tile, cloister 9.

### Rules FAQ / rulings

- **Q: Can I place on an occupied city?**  
  A: No, but you can connect.
