## 故事
白蔷薇教团要完成献祭仪式，刀刃一方潜伏在人群中，想刺杀教团首领“白蔷薇”。每一轮大家都要把一张角色牌暗中“派”进仪式，派进去的人里只要混进了一把刀，白色的人就会被杀。

## 阵营与角色牌
| 阵营 | 角色牌 | 说明 |
|---|---|---|
| 白蔷薇（白色）| **白蔷薇**（首领）| 夜里睁眼；如果和刀刃一起被翻开，刀刃方立即获胜 |
| | 司教 | 夜里睁眼（具体看到什么以说明书为准）|
| | 信者 | 普通白色牌 |
| 刀刃（红色）| **双刃**、巨刃 | 夜里睁眼；双刃可以和中央的牌交换 |
| | 暗刃 | 不睁眼的刀刃 |
| — | **幽魂** | 打出时翻开后直接弃掉，不算白也不算刃 |

- **每人拿 3 张角色牌**。手里**只要有任意一张红色牌，你就属于刀刃方**；全是白色牌才是白蔷薇方。

## 配件
- 按人数使用的玩家版图（上面印着献祭和击杀的门槛）
- 角色牌
- 12 张白水晶魔法书技能卡
- 1 枚金币（行动指示）

## 准备
1. 按人数取对应的玩家版图和角色牌，洗混后每人发 3 张，中央按规则留牌。
2. 每人拿到白水晶技能卡（按说明书分配）。
3. **夜晚**：带“眼睛”图标的角色（白蔷薇、司教、双刃、巨刃）按顺序睁眼获取信息；**双刃可以把幽魂和中央的双刃交换**。

## 每一轮
1. **传金币**：拿金币的人把金币交给一位还有白水晶的玩家，这位玩家翻开并结算一张白水晶技能。
2. **派牌**：从拿金币的人开始，按顺序**每人可以暗中打出 1 张角色牌**（也可以不打）。
3. **洗混翻开**：把打出的牌洗混后翻开，**幽魂直接弃掉**。
4. **结算**：
   - 只要翻开的牌里**有任意一把刃**，所有翻开的白色牌都进入**击杀区**；
   - 一把刃都没有，白色牌进入**献祭区**。

## 胜负
- **白蔷薇和刀刃一起被翻开** → 刀刃方立即获胜。
- **白蔷薇方获胜**：白蔷薇曾安全打出，并且在最后一轮之前献祭数达到版图上的门槛。
- **刀刃方获胜**：击杀数达到门槛；或者最后一轮结束时白方还没赢。

## 策略
- 白方：白蔷薇要挑“看起来干净”的一轮出手，同时让大家相信这轮没有刀。
- 刀刃方：手里只有一张红牌时，可以先打白牌装好人，关键轮再出刃。
- 观察谁“不打牌”，不打牌本身就是信息。

## 易错点
- 判断阵营看**手里所有 3 张牌**，不是只看第一张。
- 幽魂翻开就弃，不触发击杀。
- 献祭门槛必须在**最后一轮之前**达到，拖到最后一轮结束算刀刃赢。

## 深入玩法：教学、策略与易错点

> 本节是整理者根据上文规则和公开资料做的归纳，方便快速上手。与盒内说明书冲突时，以说明书为准。

**一句话介绍**：每人 3 张角色牌，有红牌就是刀刃方；每轮大家暗中派牌进仪式，混进刀刃白牌就被杀，白蔷薇和刀一起翻开刀刃方立即获胜。

| 维度 | 参考 |
|---|---|
| 支持人数 | 5–10 人 |
| 推荐人数 | 7-9 人 |
| 单局时长 | 20–40 分钟 |
| 建议年龄 | 8+ |
| 复杂度 | ●●○○○ 轻度 |
| 标签 | 隐藏阵营 · 推理 · 阵营 · 派对 · 快速 |

### 5 分钟教学顺序

1. 讲阵营判定（3 张牌里有红就是刀刃）
2. 夜晚睁眼顺序
3. 每轮：传金币结算白水晶、依次暗出 1 张、洗混翻开、有刃就进击杀区否则进献祭区
4. 胜负门槛

### 进阶策略

- 白蔷薇挑“看起来干净”的一轮再出。
- 不出牌也是信息。
- 刀刃方先出白牌装好人。

### 常见错误与容易混淆的规则

- 阵营看手里所有 3 张牌。
- 幽魂翻开即弃，不算刃。
- 献祭门槛必须在最后一轮之前达到。

### 适合 / 不适合

- 👍 **适合**：人多的聚会；喜欢推理、互相猜身份的朋友
- 👎 **不太适合**：暂无明显的不适合场景

## 详细补充：配件清点、示例局、计分、FAQ、人数与变体

### 配件清点清单

- [ ] 按人数使用的玩家版图（上面印着献祭和击杀的门槛）
- [ ] 角色牌
- [ ] 12 张白水晶魔法书技能卡
- [ ] 1 枚金币（行动指示）

开局前检查：
- 开盒后先按说明书的配件表逐项清点；卡牌按类型分开数，少牌会直接影响平衡。
- 确认指示物、骰子、计分轨标记齐全；缺失时可以用硬币或其他游戏的通用指示物临时代替。
- 把参考卡/玩家帮助卡发给每人，第一局能省很多翻规则的时间。

### 完整示例局（演示）

1. 7 人局，每人 3 张牌；阿明手里有 1 张红牌，所以他是刀刃方。
2. 夜里白蔷薇和司教睁眼，双刃把幽魂和中央的双刃换了。
3. 第 1 轮：金币传给小李结算白水晶；大家依次暗出牌，共 4 张。
4. 洗混翻开：3 张白牌 + 1 张幽魂，没有刃，3 张白牌进献祭区。
5. 第 3 轮白蔷薇出手时翻出一把巨刃——白蔷薇和刃一起翻开，刀刃方立即获胜。

### 计分示例

- 门槛制：献祭数在最后一轮前达到版图门槛白方胜；击杀数达到门槛或拖到最后刀刃方胜。

### 规则 FAQ / 易混淆点裁定

- **问：手里两白一红算哪边？**  
  答：刀刃方，有任意红牌就是刀刃。
- **问：幽魂会触发击杀吗？**  
  答：不会，翻开后直接弃掉。

### 不同人数的差异

- 5–10 人都能玩；人数不同使用不同版图和门槛，7–9 人最有推理味。
- 推荐人数：7-9 人。

### 官方变体与扩展

- 有 2.0 版本，部分角色与技能卡调整，以盒内为准。
