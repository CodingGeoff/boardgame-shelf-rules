# 郁金香泡沫（Tulip Bubble）

> 货架位置：A3 左侧

## 基本信息
| 项目 | 内容 |
|---|---|
| 设计 | 见 BGG 条目和盒面 |
| 出版 | Moaideas Game Design（摩艾迪亚，台湾），2015；有繁体、简体中文版 |
| 类型 | 经济、投机、拍卖 |
| 人数 / 时长 / 年龄 | 3–5 人 / 30–45 分钟 / 10+ |
| 主题 | 17 世纪荷兰郁金香狂热：低买高卖，赶在泡沫破裂前离场 |

## 配件
- 郁金香卡：**3 种颜色**（红、黄、白，以实物为准），每色分 **A/B/C 三个等级**（A 最高）
- 每色一条**价格轨道**（1–7）及价格指示物
- 事件卡（包括 **泡沫破裂 Bubble Bust** 卡）、收藏家卡
- 金币、竞价标记（每人 3 个）、融资（贷款）标记
- **黑色郁金香**卡

## 准备
1. 每色的价格指示物放在价格轨道的起始位置。
2. **准备事件牌堆**：把“泡沫破裂”卡随机洗入**最后 3 张**事件卡中，所以它会在游戏后期出现，但具体是哪一轮不确定。
3. 每人拿起始资金和 3 个竞价标记。

## 每轮流程
1. **事件阶段**：翻 1 张事件卡，影响价格或市场，并带来新的郁金香或收藏家需求。
2. **出售阶段**：玩家可以把手中的郁金香卖出，有两种方式：
   - 按**市场价**卖给银行：价格 = 该色当前价格 × 等级系数
   - 卖给**收藏家**：满足收藏家卡的要求，获得固定报价
3. **购买阶段（拍卖）**：市场上的郁金香批次逐一拍卖或竞标。每人有 3 个竞价标记，可以放在想买的批次上。
   - 钱不够时可以**融资**：拿融资标记先买下，每人最多同时持有 **3 个**。
4. **价格调整**：根据本轮的交易量和需求，各色价格上升或下降。

## 游戏结束与胜利
- **黑色郁金香**：某玩家凑出价值 **120** 的黑色郁金香时**立即获胜**（达成条件以说明书为准）。
- **泡沫破裂**：事件“泡沫破裂”翻出后，市场崩盘，游戏结束。
  - 所有郁金香的价值大幅下跌甚至归零。
  - **用融资买来但还没卖出的郁金香**会变成**债务**，要扣除。
  - 现金最多的玩家获胜。

## 策略要点
- 泡沫破裂肯定在最后 3 轮之内，但具体哪一轮未知，什么时候清仓是核心决策。
- 融资能放大收益，但到最后就是负债。
- 观察其他人收藏的颜色，避免和别人在同一色上互相抬价。
