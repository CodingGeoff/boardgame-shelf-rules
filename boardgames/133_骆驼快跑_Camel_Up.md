# 骆驼快跑 / 骆驼大赛（Camel Up）

## 核心规则
### 骆驼移动
- 5 只彩色比赛骆驼顺时针跑。第二版另有黑、白两只**疯骆驼**逆时针跑。
- 骆驼落到有其他骆驼的格子时**叠在最上面**。骆驼移动时会把**背上所有骆驼一起带走**。
- 金字塔骰：每只彩色骆驼一颗骰子（点数 1–3），外加一颗灰骰（决定黑或白疯骆驼的点数）。
- 每赛段（Leg）掷出 5 颗骰后，本赛段结束。

### 回合：四个行动选一个
1. **拿赛段押注牌**：押某只骆驼本赛段领先。赛段结束时：
   - 押中第一名：得牌面金额（通常 5 / 3 / 2）；
   - 押中第二名：得 1；
   - 其他：扣 1。
2. **放观众板块**：放在空赛道格上。“欢呼”面让落到这里的骆驼 +1 步，“嘘声”面 −1 步。每有骆驼落到你的板块上，你得 1 金币。
3. **拿金字塔票**：从金字塔里摇出 1 颗骰，移动对应骆驼，你得 1 金币。
4. **押总冠军或总倒数**：秘密押某只骆驼最终第一或最后。按押注先后，押中的人依次得 8 / 5 / 3 / 2 / 1，押错的扣 1。

### 其他（第二版）
- 疯骆驼会把它背上的骆驼往回带。
- 有“伙伴”变体规则（多人局可以组队分享押注收益）。⚠️ 细节见说明书。

## 结束
任一骆驼越过终点时游戏立刻结束。先结算当前赛段押注，再结算总冠军和总倒数押注，金币最多者胜。

## 深入玩法：教学、策略与易错点

> 本节是整理者根据上文规则和公开资料做的归纳，方便快速上手。与盒内说明书冲突时，以说明书为准。

**一句话介绍**：押注骆驼赛跑：骆驼会叠罗汉，下面的跑起来会把上面的一起驮走；押单程冠军和全程冠军。

| 维度 | 参考 |

| 支持人数 | 3–8 人 |
| 推荐人数 | 5-8 人 |

| 建议年龄 | 8+ |
| 复杂度 | ●○○○○ 入门 |
| 标签 | 押注 · 推运 · 家庭 · 派对 · 骰子 |

### 5 分钟教学顺序

1. 讲骰子金字塔（每色一次）
2. 回合四选一：拿单程押注牌、放观众板、掷金字塔骰、押全程
3. 讲叠罗汉和疯骆驼（第二版）

### 进阶策略

- 叠在最上面的骆驼最有利。
- 单程押注越早押，收益越高。
- 掷骰也有 1 镑，稳定拿钱。

### 常见错误与容易混淆的规则

- 疯骆驼倒着跑。
- 某骆驼过终点时游戏结束。

### 适合 / 不适合

- 👍 **适合**：人多的聚会；新手破冰、长辈也能马上上手
- 👎 **不太适合**：暂无明显的不适合场景
